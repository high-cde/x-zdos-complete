## 🚀 Quick Start

### Installation
```bash
git clone https://github.com/high-cde/x-zdos-complete.git
cd x-zdos-complete
npm install
```

### Run Brain Palace
```bash
npm run brain-palace:start
```

### Run Skynet AGI
```bash
npm run skynet-agi:start
```

### Run Unified System
```bash
npm run start
```

```bash
npm test
```
